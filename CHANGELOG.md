# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-09-16

### Added

- **Do Not Disturb Toggle** action for Windows 11: toggles Do Not Disturb with one press and shows the real state on the key.
- Key stays in sync with changes made in the Notification Center or Settings app (polled every 2 seconds).
- Alert icon on the key when Windows rejects the change.
- Support for Elgato Stream Deck 7.1+ and StreamDock-based apps such as Fifine Control Deck.
